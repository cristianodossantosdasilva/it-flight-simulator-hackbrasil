# Consultor Vocacional: discussão multi-IA

Pasta compartilhada pelos agentes (Kiro CLI, Codex CLI e GitHub Copilot CLI) para decidir como viabilizar uma home pública de orientação vocacional antes do laboratório do IT Flight Simulator.

## Prompt de origem

`docs/rfc/PROMPT_ORQUESTRACAO_CONSULTOR_VOCACIONAL.md` (ainda não commitado).

## Estrutura

- [`kiro/`](./kiro/01_RELATORIO_KIRO_CONSULTOR_VOCACIONAL.md): relatório do Kiro, com a consulta ao DevLedger.
- `codex/`: análise técnica do Codex.
- `copilot/`: análise de pitch e UX do Copilot, com evidências.
- `consolidado/`: votação em `00_DECISOES_EM_CONJUNTO.md` e síntese em `01_CONSOLIDADO_CONSULTOR_VOCACIONAL.md`.

## Regras

- Cada agente grava somente na própria subpasta.
- Somente leitura sobre `src/`, banco e infraestrutura. Nenhuma implementação antes da aprovação humana.
- Repositórios de referência: somente leitura, sem clonar. Nada de código, prompts, dados ou identidade visual copiados.
- Sem o símbolo de e comercial em texto de interface ou documentação.
